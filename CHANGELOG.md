# Changelog

All notable changes to LocalPlay will be documented in this file.

## 1.0.0 - 2026-08-15

### Added

- Private drag-and-drop local video playback
- Custom playback, progress, volume, speed, and fullscreen controls
- Picture-in-picture support
- WebVTT subtitle loading
- Browser-saved timestamp bookmarks
- PNG frame snapshots
- Theater mode
- Violet, Ocean, and Sunset themes
- Keyboard shortcuts
- Responsive desktop and mobile layout
- Project documentation and MIT license
